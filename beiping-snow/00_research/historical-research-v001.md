# 《北平的雪》历史考据文档 v001

> 题材：平津战役 · 北平和平解放（1948.11.29 – 1949.2.3）
> 用途：全片创作、资产、视频提示词的最高事实依据。所有日期、装束、空间方位以此为准。
> 主要来源：中央党史和文献研究院、国防部、中国军网、人民网党史频道、央视网、北京日报、光明网等

## 一、历史事件时间线（锁死，不可改动）

| 日期 | 事件 |
|---|---|
| 1948.11.29 | 平津战役开始。华北军区第3兵团（杨成武）向张家口地区开进。 |
| 12.5 前后 | 东北野战军先遣兵团（程子华、黄志勇）攻克密云。傅作义得报"攻城部队都戴狗皮帽子"，始知东野入关。 |
| 12.13 | 解放军完成对北平的合围，25 万守军被压缩进城。 |
| 12 月中旬 | **第一次和谈**：傅作义代表崔载之、李炳泉出城，在蓟县八里庄与刘亚楼接触。 |
| 12.22 | **新保安攻克**：华北第2兵团（杨得志、罗瑞卿、耿飚）+东野4纵炮兵团，7:10 总攻、156 门大炮，10 小时全歼傅系王牌第35军（军部+2 个师），军长郭景云自杀。平津战役第一仗。 |
| 12.23–24 | 张家口守敌突围被歼，张家口解放，歼敌 5.4 万。 |
| 12 月下旬 | 城内强征民夫赶修**东单操场临时机场**（限 3 日竣工）与**天坛机场**（砍天坛数百年古柏辟跑道）。 |
| 1949.1.6–1.10 | **第二次和谈**：周北峰、张东荪与林彪、罗荣桓、聂荣臻会谈，形成《会谈纪要》。 |
| 1.14 上午10时 | **天津总攻**：刘亚楼指挥，3 颗信号弹、500 多门火炮齐射。 |
| 1.14 23时 | 东西对进部队攻占**金汤桥**，将天津防御体系拦腰斩断。 |
| 1.15 下午 | **天津解放**：29 小时歼敌 13 万，天津警备司令陈长捷在警备司令部地下室被俘。我军牺牲 4106 人。 |
| 1.16 | 平津前线司令部向傅作义发出最后通牒。 |
| 1.17 | 塘沽国民党守军乘船南逃，海上逃路断绝。 |
| 1.19 | **第三次和谈**：邓宝珊、周北峰与林、罗、聂会谈，签订《关于北平和平解决问题的协议书》。 |
| 1.22 | 起休战。傅作义公布和平协议，城内 25 万守军（8 个军、25 个师）陆续开出城外接受和平改编。 |
| **1.29** | **农历春节（正月初一）**——围城之下的年关。 |
| **1.31（正月初三）** | 傅部全部撤出；东北野战军第41军121师入城接防，**北平和平解放**，历时 64 天的平津战役结束。 |
| **2.3（正月初六，"破五"之后）** | 上午10时、4 颗信号弹，举行**盛大入城式**。为让百姓过好年，入城式特意推迟到破五之后。 |

**战役数据**：平津战役历时 64 天，解放军以伤亡 3.9 万人的代价，歼灭和改编国民党军 52 万余人。

## 二、各方军装 / 装束（年代红线）

### 1. 我军——东北野战军（入城与攻坚主体）

- **帽**：**狗皮帽为图腾**（北满部队多狗皮帽，南满部队多毡绒帽）；无统一红五星帽徽、无胸章——**全军统一帽徽 1948 年 12 月之后才逐步推行，平津战役期间基本无帽徽、无胸章**。
- **衣**：土黄略带草绿色的粗布棉军装、棉大衣（侦察分队外罩缴获的美式毡绒棉猴/风衣，但属个别）。
- **装具**：绑腿、大头鞋/靰鞡鞋、干粮袋、棉手闷子；三八式步枪、缴获武器混用。
- 华北军区部队：多戴布棉帽（后方紧急定制），与东野狗皮帽略有区别。
- 入城式骑兵部队：头戴狗皮帽，骑高头大马。
- 换防初期我城防/军管人员佩戴写有"平警"的袖标。

### 2. 傅作义嫡系（晋绥军老底子：第35军、104军、105军等）

- **灰蓝/灰布棉军装**（晋绥军传统颜色），与中央军黄绿色明显不同。
- 第35军：全美械、汽车化（军长郭景云），官兵卡宾/汤姆森，配属大量美制十轮卡车。

### 3. 中央军（第13军、第94军等）

- 黄绿色棉军装，美式钢盔或棉帽，部分美式装备。

### 4. 平民（南城胡同）

- 男：中式对襟棉袄（黑、灰、藏青）、棉裤、毡帽/布帽、棉鞋。
- 女：偏襟棉袄（素色或小碎花）、围巾、头巾。
- 孩子：大人改小的棉袄棉裤、锅盖头、虎头棉鞋。
- 特征：普遍瑟缩、袖手、哈白气；衣服旧、脏、有补丁。

## 三、空间方位（胡同与城门）

- **永定门**：北平外城正南门，中轴线南起点。片中的核心空间母题。
- **永定门内大街**：南城主要街道，两侧是低矮铺面与胡同。
- **胡同**：灰砖墙、二合院、门墩、门楼、台阶；冬季堆煤、水缸结冰。
- **城墙**：高大厚重，顶部可眺望城外；城根下有贫民窟棚户。

## 四、时代细节（提升真实感的道具与环境）

| 类别 | 细节 |
|---|---|
| **货币** | 金圆券（1948 年 8 月发行，年底已暴贬）；后期民间以银元、粮食、纱布直接交易。 |
| **物价** | 1948 年冬至 1949 年初，北平物价飞涨；买粮需排长队，常有抢购、罢市。 |
| **报纸** | 《华北日报》《世界日报》《新民报》等；报童沿街叫卖。 |
| **车辆** | 洋车（人力车）、排子车、三轮车；几乎没有汽车（汽油昂贵）。 |
| **照明** | 电灯（城市贫民区常停电）、煤油灯、蜡烛。 |
| **食物** | 棒子面窝头、杂面、稀粥、咸菜、大白菜、烤白薯；白面是奢侈品。 |
| **杂物** | 火炉（煤球、劈柴）、水缸（结冰）、煤油桶、糨糊、棉门帘。 |
| **广播/声音** | 街上的电台广播（新闻、评剧）、叫卖声、炮声、飞机声。 |
| **春节** | 虽然围城，仍是年关：写春联、放鞭炮（或鸣枪代替）、包饺子。 |

## 五、事实红线（创作时不可越线）

1. **不拍统帅部运筹**——本片立场是底层凝视，镜头只跟平民与普通士兵。
2. **我军装束无帽徽胸章**——平津战役期间尚无统一帽徽，不能加。
3. **入城式在 2.3，不是 1.31**——接防与入城式是两个时间点，不能混。
4. **1.29 是春节**——围城中的年关，是重要的情感节点。
5. **天津用炮火、北平用和平**——两种解决方式构成对照，不能只讲一边。
6. **不让古建筑在大规模战斗中损毁**——和平解放的基本特征。
