# 一、墩子（主角，10 岁，南城胡同男孩）

## 基础信息
- 年龄：10 岁；角色定位：主角（孩子视角）。
- 身份：永定门内胡同人家的男孩，帮父亲跑腿、带妹妹。

## 视觉外观（资产依据）
- 面孔：圆脸，两颊冻得皴红、起皮，鼻尖通红；锅盖头、头发蓬乱；眼睛大而警觉，睫毛上常挂霜。
- 手：有冻疮、红肿裂口，指甲缝发黑。
- 着装：大人改小的灰黑色旧棉袄，肘部、袖口磨白打补丁，腰系一根麻绳；空心棉裤、绑腿；棉鞋露脚趾头，里头塞稻草；头上扣父亲的旧毡帽（大、遮住半边耳朵）。
- **服装变化**：开场尚算整齐 → 围城后期棉袄更脏更破、脸瘦一圈、嘴唇干裂 → 结尾洗过脸、棉袄仍是旧的，但人站直了、眼里有光。
- 特殊标记：左手背一块冻疮疤；总把妹妹的手塞进自己棉袄袖筒。

## 心理（路径 B：心结）
- 精神创伤：雪夜眼睁睁看父亲被拖走，觉得"是我没拉住爹"。
- 致命缺陷：恐惧时会僵住、想躲（孩子本能）。
- 渴望（外）：找到父亲、给妹妹弄一口吃的。
- 需求（内）：相信自己能撑起这个家、敢站到光里。
- 恐惧：妹妹死在自己怀里；城门再关上。
- 死寂时刻：丫丫烧得说不出话时，他不哭不喊，整个人空掉——这是他对抗世界的方式。

## 人物弧光
瑟缩偷听的孩子（雪夜被吓呆）→ 父亲走后被迫当"家里的男人"（排队、护妹、找食）→ 城墙下听炮声由怕到盼 → 永定门前踮脚迎队伍、在人群里奔跑寻父 → 含泪欢呼，雪后初晴里笑出声。

## 声音特征
- 台词短、口语、带儿化音（老北平话）；平时声小，关键处嘶喊。
- 口癖："丫丫乖，哥在呢。"；结尾："爹——！爹回来啦——！"
- 沉默：害怕和难过时不说话，只用动作（把吃的一推、手一握）。
- 台词示例：
  1. （攥着窝头、压低嗓子）丫丫，就一口，啊，哥不饿。
  2. （扒着门缝、发抖）娘，他们……他们把爹拽走了。
  3. （冲着城门、撕心裂肺）爹——！
  4. （含泪蹦跳、喊）解放了！妹妹，咱们有救了！

## 专属物件
父亲的旧毡帽、半块窝头、妹妹的手。

# 二、丫丫（妹妹，3 岁，失语对象）

- 面孔：瘦小、脸只有巴掌大，冻得发白，两个小黄毛揪揪；大眼睛。
- 着装：洗得发白的红花小棉袄（太短、露手腕），裹母亲的旧毛线围巾，虎头棉鞋。
- 状态：饿病后发烧、脸通红、哭声微弱，是全片最揪心的存在。
- 语言：只会哭、咳嗽、喊"哥……娘……"；被卫生员救活后，结尾用稚嫩声音喊"爹"。
- **功能**：她是"为什么不能打仗、为什么要保住城和家"的答案。
- 习惯动作：小手总攥着墩子的棉袄扣子；那只掉在雪地的拨浪鼓。

# 三、父亲·王德顺（德顺，36 岁，拉洋车兼木匠）

## 基础信息
- 36 岁；一家之主；早年在木厂学徒，平日拉洋车、红白喜事做木工活。

## 视觉外观
- 面孔：黑瘦、颧骨高、胡茬重，额头有抬头纹，眼神忠厚；手上全是老茧和木刺伤。
- 着装：藏青短棉袄、挽着袖口，腰间挂木匠小兜（尺、墨斗），脖上缠灰围脖，黑棉鞋；拉洋车时垫肩。
- 变化：被抓后换上劳工的破棉袄、棉帽，在机场工地扛木料/推石碾，脸更黑瘦、手上加新伤；结尾随解放军入城时衣衫破旧但站直了。

## 心理与弧光
- 本分人，信"忍一忍就过去了"；雪夜为护家人想顶上去，被强行拖走。
- 在工地目睹高官坐飞机逃命、自己如草芥，从"忍"到"恨"；被解放军解救后成为支前/入城队伍中的一员。
- 渴望：让孩子吃上饱饭、活着回家。
- 声音：话不多、嗓音低沉，急了会吼；口癖"有爹在，饿不着你们。"
- 台词示例：
  1. （被按住、挣扎怒吼）放开我！家里还有仨孩子——！
  2. （雪夜塞窝头、哽住）墩子，拿着……护好你妹妹，等爹回来。
  3. （重逢、泣不成声）丫丫……爹的丫丫……

## 专属物件
墨斗、木匠小兜、给丫丫做的拨浪鼓、洋车。

## 这份文档的结构说明

每个角色都按固定字段写：基础信息 → 视觉外观 → 心理 →
弧光 → 声音特征 → 专属物件。这个顺序不是为了好看，
是因为**不同字段服务不同下游阶段**：

| 字段 | 服务于 |
|---|---|
| 视觉外观 | 阶段 06 资产生成（面孔/着装/特殊标记直接转提示词） |
| 服装变化 | 关键——告诉资产阶段同一角色需要几套服装变体 |
| 声音特征 | 阶段 07 表演（台词示例直接给配音参考） |
| 专属物件 | 阶段 03 资产登记（哪些道具要单独建资产） |
| 心理/弧光 | 表演阶段把握情绪递进依据 |

**「服装变化」这一节尤其重要**
写清了开场→围城后期→结尾三个阶段的外观差异。
AI 生成角色资产时，如果不说明需要几个变体，
很容易全程用同一套形象，角色就没有时间流逝感。

**总原则里那句「无明星脸」也是约束**
避免 AI 生成网红脸、精修脸——那与贾樟柯式纪实
与底层凝视的创作立场相悖。
